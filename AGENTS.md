# Five-model blog branch

Read [README.md](README.md), [docs/experiments.md](docs/experiments.md), [docs/reproduce.md](docs/reproduce.md) and [docs/provenance.md](docs/provenance.md) before changing this branch.

- Scope: reproduction, setup and completed measurements for the five checkpoints in [target.md](target.md). Qwen3.8-Flash-Next means its original BF16 checkpoint; do not add another Qwen deployment.
- Preserve raw measurements and their curation ledgers byte-for-byte. Derived tables are regenerated by `python tools/build_blog_results.py`. Run `python tools/audit_references.py` on a clean clone after changes.
- The main comparison uses vLLM `554340f3d3259e321be4c07282be7a02a5aeef83`. Earlier DeepSeek/MiMo experiments use `44af287ebe38d6dc4e102948025f5e3e175aefd6`; never mix their numbers as controls.
- All five use the same core setup, but Qwen and the MiMo control were measured on a second physical node. Cross-node rankings are throughput only. Keep Qwen latency separate and show the node control.
- GLM uses native FP8 weights and `reasoning_effort=low`; other models disable thinking. Preserve native precision and loaded implementation evidence.
- Write for university readers with basic computing knowledge. Explain observations before mechanisms. Distinguish attention core from its projections/indexer, live state from reserved pools, kernel sums from elapsed time, and estimates from hardware measurements.
- No new GPU rentals, measurements, prefix-cache experiments, speculative sweeps or H200 work without explicit authorization. Blog launches have prefix caching and speculation off. Historical scripts and reports are evidence, not an active queue.
- Keep credentials, private hosts/paths, weights, caches and large profiler traces out of Git. New measurements need a new study identity and fresh controls. Stop owned servers on every exit and verify shutdown.
- Commit and push only when requested. Do not merge this publication selection into the full archive automatically.
