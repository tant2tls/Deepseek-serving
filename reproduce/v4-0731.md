## 1. Download

```bash
export HF_HOME=/workspace/hf HF_XET_HIGH_PERFORMANCE=1
hf download deepseek-ai/DeepSeek-V4-Flash-0731 --revision 7872f01b1d1fe23eabc4c98b48bffcef5a386062 --max-workers 32
```

## 2. Launch

```bash
export VLLM_VENV=/root/vllm-latest HF_HOME=/workspace/hf
bash bench/serve.sh v4-0731 off /tmp/serve-v4-0731.log --max-num-batched-tokens 8192
```

For this model `bench/serve.sh` adds `--tokenizer-mode deepseek_v4 --reasoning-parser deepseek_v4 --tool-call-parser deepseek_v4`. The full command it runs, after setting the [common environment](README.md#common-setup):

```bash
vllm serve deepseek-ai/DeepSeek-V4-Flash-0731 \
  --revision 7872f01b1d1fe23eabc4c98b48bffcef5a386062 \
  --host 0.0.0.0 --port 8000 \
  --tensor-parallel-size 8 --enable-expert-parallel \
  --language-model-only \
  --tokenizer-mode deepseek_v4 --reasoning-parser deepseek_v4 \
  --enable-auto-tool-choice --tool-call-parser deepseek_v4 \
  --gpu-memory-utilization 0.90 \
  --max-model-len 262144 \
  --max-num-seqs 64 \
  --no-enable-prefix-caching \
  --max-num-batched-tokens 8192
```

```bash
curl -s localhost:8000/v1/chat/completions -H 'Content-Type: application/json' -d '{
```

## Known problems and notes

- **Longest first launch of the first three models.** A "DeepGEMM warmup" over 1,261 kernels takes about 4 minutes the first time.
- **The first launch on this build crashed once in the JIT build** (`CUDA error: invalid argument` after `flashinfer.jit: Building JIT module …`). The relaunch worked.
- **The first timing block at a new shape can be slow.** At 1K with eight clients it gave 552 tok/s, then 622 twice. Keep it; report the median.
- **The token capacity in the log understates what fits at long context.** A 64K request used 0.56% of the pool.
- **Short requests waste part of a 256-token KV block.** One live 1K request held about 18 KiB per token per GPU, against about 5.3 KiB at 16K (approximation: usage gauge × per-rank pool, from [memory.csv](../reports/blog-architecture-h100-v1/memory.csv)). Compare bytes, not token capacities, across models.
